Reading the rates

Response tokens/s is output excluding reasoning divided by turn wall time. Total tokens/s includes input and output, including cached input. Wall time includes requests, tools, and waiting; these are not decode speeds.

About this snapshot

Ultra is excluded from this campaign. Unmeasured means no saved attempt; unsupported means the catalog did not advertise that configuration. A 429 is a provider error, not proof that Fast is unavailable.

Means use up to the three most recent completed runs with the same task and task version as the latest measurable run. Runs lacking a verified task version are shown individually. Failed attempts are retained in the details. Refresh the snapshot to include newly saved results.
